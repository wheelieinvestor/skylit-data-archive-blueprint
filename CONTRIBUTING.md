# Contributing

Improvements to the explanations, diagrams, metadata templates, public source links and agent prompts are welcome. Keep examples portable and identify implementation requirements separately from functionality shipped here.

Before a pull request:

1. Run `python3 scripts/check_blueprint.py`.
2. Review all changed files and links.
3. Include no collected responses, real symbol lists, datasets, private resource IDs, credentials, screenshots of private dashboards or operational logs.
4. If you update a cost or provider behavior, cite the current primary source and date the claim.
5. Do not copy private repositories or their Git history into this project.

The offline check detects common accidental additions. It is not a guarantee that arbitrary material is safe to publish; inspect your diff. Use schema definitions or blank templates instead of real sample payloads.
